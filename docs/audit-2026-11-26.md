# Audit: Trend Join Long paper setup (2026-11-26)

Scope: branch `claude/loving-davinci-phos45` at `c1f2b29` (read-only audit; nothing fixed). Source of truth for rules: `docs/intraday-stock-research.md` ("the doc").
Checks run: `python3 -m pytest tests/test_tjl.py -q` (19 passed), probe scripts against the code, read-only calls: Liquid `paper_trading_status` (ENABLED) and `analyze_market xyz:MU`, Webull `get_stock_snapshot` and `get_stock_bars` (PRE 5m, SPY daily in July), Notion schema fetch of "TJL Trades", the dashboard's datasets and page code. Figma could not be read (Figma MCP Starter-plan call limit).

## 1. Verdict
The rule logic is mostly faithful to the doc and the 19 tests pass, but the setup is not ready to produce trustworthy data on Mon 11/30. Four things break it. (1) If the trigger runs without `--now`, which is how the routine runs it, an in-progress 5m bar counts as complete, so version B can pass its 10:05 window at 10:02. (2) The morning check silently uses the wrong session date after a skipped after-close. Monday morning on the 11/25 state would evaluate 11/27, a half day. (3) Every exit, stop move and the 15:51 flatten depends on you sending a message. (4) Nothing checks margin across carried positions, new trades and RSI(2) on the shared $10k account. The measurement layer has smaller biases: profit factor in $ instead of R, R taken from planned risk instead of actual risk, A/B alternation that tilts paired days toward A, and shadow rows simulated more kindly than real fills. Each one moves the go/no-go numbers. The evidence base is weak to begin with: her own bot lost money on paper. So the paper test is worth running only after the critical fixes, and the real goal should be an automated paper bot on a broker with an API, because Liquid's approval on every order can't run unattended.
